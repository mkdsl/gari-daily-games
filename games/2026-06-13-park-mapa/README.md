# Park Mapa

**Žanr:** Ambient Persistent Experience / Interactive Map
**Datum:** 2026-06-13
**Branding:** MKDSLend ⭐ × Kluboslavija × Guncati

> MKDSLend Park je živi piksel-art svet — istraži 3 zone, skupljaj Parktokene, gledaj park kako raste kroz sezone.

## Kako se igra

- 3 zone: **Pult** (Kluboslavija bina), **Bina** (main stage), **Šuma** (Guncati nature zone)
- Dnevni ritual: Dnevno Svetlo check-in + easter egg hunt → Parktokeni
- Sezonski rast — park vizuelno evoluira
- Pasivni ambijent: klikćeš kad poželiš, napredak traje

## Brend

Krovni MKDSLend world koji spaja sve projekte u jedan persistent prostor. Bina zona nosi Kluboslavija event sadržaj.
