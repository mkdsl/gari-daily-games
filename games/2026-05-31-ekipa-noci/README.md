# Ekipa Noći

**Žanr:** Card / Kombinator — Multi-Layer Crew Builder

**Branding:** Kluboslavija ⭐ × MKDSLend

> Ti si Crew Manager Kluboslavija turneje. Za svaki event draftuješ ekipu iz karata — hemija pravi noć, slaba ekipa = prazna bina.

## Kako se igra

- Špil karata: DJ, Host, Sound, Video, Security — svaka sa atributima
- Draft faza: biraš ekipu u okviru budžeta
- Izvođenje: event se odigrava na osnovu kombinacije
- Sinergije i anti-sinergije — pravi "vibe score"
- Prestige: opet kreiraš špil sa boljim kartama
