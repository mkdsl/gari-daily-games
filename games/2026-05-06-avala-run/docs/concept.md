# Avala Run — Koncept

**Naziv:** Avala Run  
**Zanr:** Endless Runner / Arkada / Eko  
**Datum:** 2026-05-06  
**Projekat:** Kluboslavija — branded asset za festival Avala, 20. jun 2026.

## Premisa
DJ koji kasni na Avalu trci kroz nocnu/sumracnu sumu sa torbom opreme. Svaki kasniji dolazak je bolji od nikad. Skuplja karte za festival i cisti smece sa planine.

## Core Gameplay Loop
Trcis automatski desno. Preskakas prepreke (bor, kamen, kamion) ili se priginjavaš pod dronom. Skupljаs zlatne karte (+10 poena + boost) i smece (zaseban counter). Game over na prvom sudaru.

## Hook
Daily highscore lista — top 3 po score i top 3 po skupljenom smecu. Dve paralelne liste, dve strategije. Svaki dan pocinje ispocetka.

## Vizuelna Estetika
Pixel art, tamno plava paleta, topli narandzasti/crveni tonovi na vrhu neba (hint festivala). DJ silueta sa slusalicama i torbom.

## Audio Mood
Subtilni bass beat koji traje tokom trcanja, "ding" za svaku skupljenu kartu, "klank" za smece.

## Win Condition
Sto duze prezivIs, veci score. Pobednici daily highscore-a dobijaju kartu za pravu Avalu 20. juna.
