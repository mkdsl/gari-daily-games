# Avala Run

**Žanr:** Endless Runner / Arkada / Eko  
**Datum:** 2026-05-06  
**Projekat:** Kluboslavija — branded asset za festival Avala, 20. jun 2026.

## Opis

DJ koji kasni na Avalu trči kroz noćnu šumu sa torbom opreme. Skupljaj zlatne karte i čisti smeće sa planine, preskakaš borove i kamenje, priginjavaš se pod dronovima. Svaki dan novi highscore.

## Kako se igra

| Kontrola | Desktop | Mobilni |
|----------|---------|--------|
| Skok | ↑ / Space / W | Tap gornja polovina |
| Duck | ↓ / S | Tap donja polovina |

## Kolektibli
- **🎫 Karta** — +10 poena + kratki speed boost
- **🥫 Limenka / 🍶 Flaša / 📄 Papir** — trash counter +1

## Prepreke
- **Bor, Kamen, Kamion** → skok
- **Dron** → duck

## Daily Highscore
Dva dnevna ranga — top 3 po score i top 3 po skupljenom smeću. Reset svakog jutra.
