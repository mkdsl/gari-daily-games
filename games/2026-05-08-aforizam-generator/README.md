# Aforizam Generator
**Pera Period × Kluboslavija** — 2026-05-08

## Šta je ovo

Generativna estetska alatka. Klikneš dugme, dobiješ aforizam u Pera Period stilu — telesno-filozofski, eko-poetski, ironično-mistično, ili iz klupske/plesne sfere. Kopiraš, nalepiš u IG story, Kluboslavija watermark putuje sam.

## Kako se igra

1. Otvori stranicu
2. Čitaj aforizam koji se pojavi
3. Klikni **Sledeći** za novi
4. Klikni **Kopiraj** → nalepi u IG story / poruku

Nema scoreova. Nema game overa. Cilj je jedan: deli ono što zvuči kao da je pisano o tebi.
